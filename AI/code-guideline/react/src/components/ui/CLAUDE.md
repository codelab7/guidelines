# src/components/ui - UI Library Wrappers

Thin wrappers around the components of the project's UI library, such as Mantine or MUI, and any files a UI library tool generates into the project.

## Structure

- One file per wrapped component, named after it: `button.tsx`, `modal.tsx`.

## Rules

- Wrap a component only to set project defaults: size, variant, common props.
- No domain knowledge, no data fetching, no business rules.
- A new style or variant goes in the UI library's theme or in the wrapper here, and is recorded in the list below. New behaviour or project logic goes in a wrapper in `shared/`.
- Files generated by a tool are exempt from the style rules in `src/CLAUDE.md`. Never reformat them. Keep local edits minimal so an update can still be applied.

## Boundaries

- Follow the `components/ui/` row in the import table in `src/CLAUDE.md`. Never import from another `components/` folder.
- Not here: a component that needs project context belongs in `shared/`.
