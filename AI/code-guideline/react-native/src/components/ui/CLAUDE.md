# src/components/ui - UI Wrappers

Thin wrappers around the components of React Native and the project's UI kit, and any files a UI kit tool generates into the project.

## Structure

- One file per wrapped component, named after it: `button.tsx`, `text.tsx`, `text-input.tsx`.

## Rules

- Wrap a component only to set project defaults: size, variant, theme values, common props.
- No domain knowledge, no data fetching, no business rules. A button does not know what a sale is.
- A new style or variant goes in the theme or in the wrapper here, and is recorded in the list below. New behaviour or project logic goes in a wrapper in `shared/`.
- This is where cross-cutting behaviour is enforced once: press feedback and haptics, the minimum 44pt touch target, the disabled and loading states, font scaling, and the accessibility role. A screen should never re-implement them.
- Files generated by a tool are exempt from the style rules in `src/CLAUDE.md`. Never reformat them. Keep local edits minimal so an update can still be applied.

## Boundaries

- Follow the `components/ui/` row in the import table in `src/CLAUDE.md`. Never import from another `components/` folder.
- Not here: a component that needs project context belongs in `shared/`.
